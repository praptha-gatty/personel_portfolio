# Personal Portfolio Website

A simple beginner-friendly portfolio website built using Next.js, React, CSS and Lucide React icons.

## Run the project
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Before submitting
- Replace `YOUR_EMAIL@example.com` with your email address in `components/HomePage.js`.
- Update the GitHub and LinkedIn links with your own profile links.
- You can replace the PG circle with your own profile photo later.
